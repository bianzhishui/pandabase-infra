# pandabase-infra

## 是什么

pandabase 系列业务的共享底座。对应能力：域名与 TLS、身份（Casdoor）、PostgreSQL、容器网络、
备份与升级。不承载业务逻辑。

## 约束

| 约束 | 来源 | 影响 |
|---|---|---|
| 单机 2C2G、无 HA | 成本 | 所有组件同机；升级必须留窗口与回滚路径 |
| 单人维护 | 人力 | 不引需要专职运维的组件（K8s、服务网格、消息队列） |
| 业务仓库独立 | 组织 | infra 不引用业务路径；契约只公布值，不规定变量名 |
| 反代不做鉴权 | 安全（见 ADR 0001） | `/mcp` 的令牌校验必须在业务进程内完成 |

## 业务边界

- 属于 infra：域名/TLS、Casdoor、PG 实例与库角色、容器网络、备份、PG 版本升级
- 属于业务：镜像构建、compose 编排、表结构与迁移、令牌校验逻辑、审计日志
